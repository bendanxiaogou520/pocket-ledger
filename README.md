## 中文

### 为什么有它

市面上的记账 App 都要注册、要联网、要会员，还要把账目传到别人服务器上。

Pocket Ledger 反着来：**没有账号，没有网络权限，数据只写在手机本地**。卸载就等于全清，所以它自带导出备份。

### 功能

| 模块 | 内容 |
| --- | --- |
| 账本 | 记一笔、分类、按天/按月汇总 |
| 待办 | 星标、截止日期、拖拽排序，和账本共用一套顶部胶囊切换 |
| 外观 | 主题皮肤（含深色）、液态玻璃导航、弹簧动效 |
| 备份 | 一键导出 JSON 到 `Documents/玽记/`，换机不丢账 |

### 怎么装

1. 点上面的 **下载最新版**（约 2.7 MB）
2. 手机提示「不允许安装未知应用」→ 这一次允许
3. 装完打开就能用

**系统要求**：Android 8.0 及以上。

> ⚠️ 卸载 App 会清空本地账目。换机或重装前，先在 App 里导出备份。

## English

### Why it exists

Every expense app wants an account, a subscription, and your data on their server.

Pocket Ledger does the opposite: **no account, no network permission, everything stays in local storage.** Uninstalling wipes it, so one-tap JSON export is built in.

### Features

| Module | What you get |
| --- | --- |
| Ledger | Quick entry, categories, daily and monthly totals |
| To-do | Stars, due dates, drag-to-reorder, sharing a top pill switcher with the ledger |
| Looks | Theme skins (incl. dark), Liquid Glass navigation, spring animations |
| Backup | One-tap JSON export to `Documents/玽记/` |

### Install

1. Download the APK above (~2.7 MB)
2. Allow "install unknown apps" once when prompted
3. Open it — that's it

**Requires** Android 8.0 or newer.

> ⚠️ Uninstalling clears your data. Export a backup before switching phones.
